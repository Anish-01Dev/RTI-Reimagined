# Frontend

React + TypeScript client, built with Vite.

## Layout

```
src/
├── components/   Reusable UI components
├── pages/        Route-level views
├── hooks/         Shared React hooks
├── services/      API client and data-fetching logic
├── offline/       IndexedDB-backed offline case store and sync queue
└── types/         Shared TypeScript types
```

## Local Development

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
